# 🍽️ Restaurant Order Analysis using MySQL

## 📌 Project Overview

This project focuses on analyzing restaurant sales and customer ordering behavior using MySQL. The analysis was performed on 12,234 restaurant order records and 794 menu items to identify customer demand patterns, top-selling products, category performance, and revenue-driving menu items.

The main objective of this project was to generate business insights that can help restaurants improve menu planning, optimize product performance, and support revenue-focused decision making.

---

# 🎯 Business Objectives

* Understand customer ordering behavior
* Identify top-selling and low-performing menu items
* Analyze category-wise product performance
* Study demand patterns across menu items
* Support menu optimization and pricing decisions

---

# 🗂️ Dataset Information

## 📋 Tables Used

### 1️⃣ menu_items

Contains information about restaurant menu products.

| Column Name  | Description             |
| ------------ | ----------------------- |
| menu_item_id | Unique ID for menu item |
| item_name    | Name of dish/product    |
| category     | Food category           |
| price        | Product price           |

---

### 2️⃣ order_details

Contains customer order transaction details.

| Column Name      | Description           |
| ---------------- | --------------------- |
| order_details_id | Unique transaction ID |
| order_id         | Unique order number   |
| order_date       | Order date            |
| item_id          | Ordered menu item     |
